# v1.4.0 怪物群体稳定性修复

日期：2026-11-01

## 一、真机问题

Android 试玩中，多只绿色怪物靠近玩家后会互相重叠并快速抖动。现象在开镜、换武器或玩家停下时更明显，但武器系统没有直接修改怪物状态；这些操作只是让玩家暂时停止移动，使原有 AI 边界问题集中暴露。

同时，角色外观并不像僵尸，因此普通怪物改名为“哥布林 / Goblin”，紫色精英改名为“深渊蛮兵 / Abyss Brute”，玩法说明统一使用“怪物”。第三方素材包 `Quaternius Zombie Apocalypse Kit`、资源目录和原始资源文件名按许可证与引用关系保留。

## 二、根因

1. 追击和攻击共用单一距离阈值，怪物在临界距离会逐帧切换 `Chase` 与 `Attack`。
2. 所有怪物都把玩家中心作为终点，没有群体分离，多个 CharacterController 会争抢同一个位置。
3. 旧视线 Linecast 会把另一只怪物的碰撞体当成墙，导致 `Chase / Search / Attack` 额外跳变。

## 三、实现

- `EnemyDecisionModel` 使用攻击迟滞：追击状态进入攻击的距离为 `1.34m`，已在攻击状态时超过 `1.72m` 才退出。
- `EnemyAgent` 维护当前活跃怪物集合，在 `1.2m` 范围内计算分离方向；分离移动独立于寻路和攻击执行，因此停在玩家身边时仍会拉开间距。
- `EnemyPerception` 使用无分配射线查询，并忽略自己、玩家和其他 `EnemyAgent`；墙体与场景实体仍然阻挡视线。
- 对象池、出生预警、运行时对象和视觉节点采用 `Monster`、`Goblin`、`Abyss Brute` 命名。
