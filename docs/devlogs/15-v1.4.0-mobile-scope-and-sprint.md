# v1.4.0 移动端开镜与冲刺交互修正

日期：2026-11-01

## 试玩反馈

上一轮解决了 HUD 重叠和浮动摇杆，但真机试玩继续暴露出两个交互问题：

1. 冲刺按钮按下时开启、松手时关闭，所以普通点击几乎看不到效果；按钮又位于左半屏移动触区附近，容易与摇杆触点竞争。
2. 开镜按钮沿用了桌面端“按住右键”的语义，手指离开按钮后立即退镜，无法像主流移动射击游戏一样先开镜、再独立点击射击。

## 输入状态改造

`GameInput` 不再用一个临时按住布尔值同时表达所有移动端状态，而是区分：

- `mobileAim`：点击开镜后的切换状态；
- `mobileSprintButton`：点击冲刺按钮后的锁定状态；
- `mobileAutoSprint`：摇杆上推进入冲刺门槛后的自动前进状态。

开镜按钮每次点击切换一次。松手不再关闭开镜；再次点击、手动换弹、切换长刀、死亡、暂停或离开战斗流程会关闭开镜。

冲刺按钮同样使用点击切换。按钮移到屏幕中下方，脱离左半屏浮动摇杆触区，并通过绿色高亮表示当前锁定状态。

## 摇杆自动冲刺

浮动摇杆出现后，会在上方显示冲刺门槛：

```text
左半屏按下
→ 拖动摇杆移动
→ 向正前方拖过冲刺门槛
→ 输入锁定为向前冲刺
→ 松手后继续自动前进
```

自动冲刺可通过再次触碰左半屏摇杆或点击冲刺按钮解除。横向偏移过大时不会误触自动冲刺，普通拖动和松手仍按原规则归零。

## UI 与教学

- 战斗界面右侧继续只保留攻击、开镜、装弹、切枪、切刀和视角按钮；
- 冲刺按钮位于中下方，避开左半屏摇杆和角色主体；
- 开镜、冲刺锁定时按钮高亮；
- 关卡准备页说明改为“摇杆上推自动冲刺、点击开镜切换、点击冲刺锁定”，说明没有重新塞回战斗 HUD。

## 仍需真人确认

自动测试证明状态切换和输入边界，没有代替 Android 真机手感。覆盖安装后重点检查：

1. 点击冲刺能否稳定锁定和解除；
2. 摇杆上推自动冲刺是否容易触发但不会误触；
3. 点击开镜后能否松手，再点击攻击射击；
4. 开镜状态下装弹、切刀、暂停是否正确退镜；
5. 左手移动或自动冲刺时，右手能否同时转向、开镜和射击。

## 面试讲法

> 移动端不能直接照搬桌面端的按住输入。第一版把开镜和冲刺都写成 PointerDown 开启、PointerUp 关闭，真机上会占用手指，无法同时完成瞄准和射击。我把输入拆成开镜切换、冲刺按钮锁定和摇杆自动冲刺三个状态，并规定换弹、切刀、暂停等退出条件。PlayMode 通过真实指针事件验证按下、松手、再次点击和摇杆上推，避免 UI 看起来存在但实际不可操作。
