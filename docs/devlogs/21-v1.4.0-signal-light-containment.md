# v1.4.0 终点与出生预警灯光收敛

日期：2026-11-04

## 一、试玩反馈

作者确认第一人称侧墙检测和第三人称武器比例已经正常，随后指出终点绿色点光源与怪物出生红色点光源过亮：靠近对应区域时，即使隔着迷宫墙体也能看到明显染色，既影响画面，也会泄露终点或出生位置。

## 二、原因

- 终点灯原范围为 `10m`、强度为 `3`，且没有阴影。
- 普通/精英出生灯范围分别为 `5m`、`7m`，脉冲强度最高达到 `4`，且没有阴影。
- 发光材质的 emission 同样偏高，进一步放大了局部高亮。

## 三、修改

- 终点灯范围从 `10m` 降至 `4.8m`，强度从 `3` 降至 `0.8`。
- 终点门框发光强度从 `0.6` 降至 `0.3`。
- 普通/精英出生灯范围降至 `2.6m`、`3.4m`。
- 出生灯脉冲改为 `0.25-0.9`，不再达到 `4`。
- 出生标记发光强度从 `0.6` 降至 `0.25`。
- 终点灯和出生灯均启用硬阴影，阴影强度为 `0.7`，墙体参与遮挡。
- 出生标记持续时间、敌人生成规则、终点触发器和关卡路线没有修改。
