# v1.4.0 死亡结算装备遮挡修复

日期：2026-11-04

## 一、真机反馈

最新 Android 包中，怪物近距离追击已经正常，暂未再次出现鬼畜。玩家死亡倒地并弹出失败结算时，角色前方偶尔出现一块大型板状模型，遮挡结算背景。

## 二、根因

角色同时维护手持武器和背负武器。背负武器挂在 `Torso` 胸骨下，死亡动画会让胸骨大幅旋转；背负狙击枪随骨骼转到第三人称相机近处后，模型被近裁剪，看起来像突然出现一块板。第一人称武器挂点原来也只根据视角和配镜状态控制，没有把死亡纳入显示条件。

## 三、实现

- `PlayerVisual` 首次检测到死亡时隐藏手持狙击枪、手持长刀、背负狙击枪和背负长刀。
- `WeaponController` 在死亡状态关闭第一人称武器挂点。
- 重新挑战时先恢复生命，再由 `PrepareLoadout` 和 `Equip` 恢复默认长刀与背负狙击枪。
- 不修改死亡动画、角色模型、武器数值和正常换枪逻辑。
