# Maze Escape v1.4.0 Release Candidate

状态：功能分支发布候选，尚未合并或公开发布。

## 玩家可见变化

- 玩家默认手持长刀，同时携带栓动狙击枪，可使用 `1 / 2`、鼠标滚轮或移动端按钮切换，不再经过武器选择页。
- 狙击枪为高伤害单发武器，使用 5 发弹匣和 20 发备用弹药；每枪后必须拉栓，空弹不会自动换弹，必须按 `R` 或移动端换弹键。
- 鼠标右键或移动端配镜键进入 24 度 FOV 配镜视角；每次刚开镜的前 3 秒使用 0.5 倍时间流速，随后保持配镜但恢复正常速度。
- 第一人称眼位移回角色碰撞胶囊内部并使用 0.03 近裁剪面，修复贴墙时视野穿墙。
- 狙击枪与长刀使用双手支撑姿态，未使用的武器显示在角色背部。
- 换弹期间允许移动和转向，切换长刀会中断换弹并保留当前弹药状态。
- 新增双武器槽 HUD、弹匣与备用弹药、换弹进度、空仓提示、长刀冷却和武器专属准星。
- 普通怪物命名为哥布林，紫色精英命名为深渊蛮兵；玩法说明统一使用“怪物”。
- 怪物视觉受距离、视野角、墙体遮挡、环境光和局部雾区影响。
- 枪声、长刀攻击和冲刺脚步声使用不同传播半径；怪物会前往声音位置调查。
- 怪物失去视野后搜索最后已知位置，附近怪物只接收有半径和冷却限制的可疑位置警报。
- 删除短局内连续昼夜循环，十关改用供电、低照明、应急红灯、断电、污染、封锁和地下深层等固定环境状态。
- 局部雾区同时使用空间粒子、HUD 后层雾幕和状态提示，并降低区域内怪物视野。

## 工程改造

- `WeaponController` 把已拥有武器、当前武器、弹匣、备用弹药和瞬时动作分开管理。
- `EnemyPerception` 负责视觉、听觉和目标记忆。
- `EnemyDecisionModel` 使用可独立测试的 Utility 分数选择巡逻、调查、搜索、追击或攻击。
- `EnemyAgent` 保留已有网格 A*、移动、攻击、动画和对象池执行职责。
- `NoiseSystem` 统一广播枪声、刀声、脚步声和有限群体警报。
- `LevelDefinition` 用 `DungeonCondition` 和局部雾区数量替代短局昼夜参数。

## 2026-11-01 移动射击操作修正

- 开镜从“按住按钮”改为“点击切换”，松手后保持配镜，可再用右手点击攻击。
- 手动换弹、切换长刀、暂停和退出战斗会清理移动端开镜状态。
- 冲刺按钮从按住改为点击锁定，并移到中下方避开左半屏摇杆触区。
- 浮动摇杆增加上推冲刺门槛；拖过门槛后松手继续自动前进，再次触碰摇杆或点击冲刺键解除。
- 开镜和冲刺锁定时按钮使用高亮反馈，关卡准备页同步更新操作说明。
- 新增开镜切换、冲刺点击锁定和摇杆自动冲刺 PlayMode 测试。

## 2026-11-01 怪物群体稳定性修正

- 修复玩家开镜、换武器或停下后，多只怪物挤向同一目标点并在攻击距离边缘反复切换状态的问题。
- 追击进入攻击使用 `1.34m` 阈值，已攻击的怪物超过 `1.72m` 才退出，形成迟滞区间。
- 活跃怪物在 `1.2m` 内执行独立分离移动，追击和攻击状态都不会继续完全重叠。
- 视线射线忽略其他怪物，只让墙体和场景实体阻挡玩家视线，避免同伴经过时错误切换搜索状态。
- 新增攻击迟滞、同伴不遮挡视线和近距离群体分离测试。

## 2026-11-03 近距离攻击与刷怪增压

- 可见玩家进入 `4.5m` 后，怪物不再只追逐 A* 最终格中心，而是直接追向玩家实际位置，避免玩家站在格子边缘时怪物停在附近。
- `2.4m` 内的近身感知不受前向视野角限制，但仍检查墙体遮挡；怪物从玩家身边经过或被分离转向后不会退回搜索或巡逻。
- 第一关敌人上限由 4 提高到 6，刷怪间隔由 6.0 秒缩短到 4.2 秒；第十关上限由 14 提高到 18，间隔由 2.5 秒缩短到 1.8 秒，中间关卡平滑递增。
- 开局第一次预警由 1.2 秒提前至 0.8 秒，仍保留出生预警和离玩家 12 米的安全距离。
- 新增“近身背向仍感知”和“从远处追到静止玩家后进入攻击并扣血”两项 PlayMode 回归。

## 2026-11-04 死亡结算装备遮挡修复

- Android 真机确认近距离追击已恢复正常，暂未再次出现怪物鬼畜。

- 重新挑战时按默认长刀配置恢复手持长刀和背负狙击枪，不影响正常换枪流程。
- 新增死亡隐藏四个武器显示对象、重开恢复默认配置的 PlayMode 回归。

## 2026-11-04 靠墙收枪与武器模型防穿墙

- 真机确认死亡结算板状遮挡已经消失，随后发现角色贴墙时手持狙击枪或长刀模型会伸入墙面。
- `WeaponController` 从玩家胸口沿朝向执行无分配球形检测，只把墙体和场景实体计入遮挡，怪物不会触发收枪。
- 第一人称武器根据遮挡距离平滑向后下方移动并旋转为低持姿态；离墙后平滑恢复原挂点。
- 第三人称双手目标同步移向胸前，缩短手持武器的前伸距离，避免只修镜头武器而角色模型仍穿墙。
- 原有枪口到目标、胸口到枪口和长刀到目标的墙体判定继续保留，视觉收枪不替代伤害阻挡。
- 新增靠墙收枪量、第一人称挂点后移、第三人称前伸缩短和离墙恢复测试。
